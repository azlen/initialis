INITIĀLIS: an endless explorer for ornamental drop caps, illuminated lettering, and new typographic aesthetics, each drawn in the browser. Pick one and find more like it; save it, see it set as the opening of a printed page, download it as transparent PNGs, an animated WebP (also transparent) and an MP4, or share a link to it; bookmarked ones can be seen, downloaded and shared all together. A collection link (?c=…) opens as a page of its initials. For agents: https://initialis.azlen.me/llms.txt explains share links (?i=…), how to read an initial's settings, and how to use one in a project.
