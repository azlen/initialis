INITIĀLIS as a library

Any initial from the field on your own page, drawn in the browser as the site draws it: one tag, or a few calls. It brings its own render workers and fetches the fonts from the site, so it works from anywhere. It needs WebGL2 in web workers: any current Chrome, Edge or Firefox, Safari 17 or later.

A tag, and an initial's settings

Load the library once, then give the tag an initial's settings: only what differs from the defaults. {"text":"Q"} alone is a Q in the default style; a few more keys change its face, frame and inks. Every setting, with its range, is PARAMS in render/src/params.js. A downloaded initial's .json has them as params, and any share link gives them with &format=json on the end.

<script type="module" src="https://initialis.azlen.me/lib/initialis.js"></script>
<initialis-cap settings='{"text":"Q"}' size="200"></initialis-cap>
<initialis-cap settings='{"text":"Q","font":"cinzel-700","frame":"circle","inkA":"#23305e"}' size="200"></initialis-cap>
<initialis-cap settings='{"text":"R","font":"cinzel-700","frame":"circle","inkA":"#23305e","inkB":"#cb1b45","oFill":"B"}' size="200" paper></initialis-cap>

The last is printed on its own paper (paper) rather than the ink alone on a transparent ground.

From a share link

src takes a link copied from share, or just its code. A long link carries the settings in itself; a short one is looked up on the site each time a page shows it, so for keeps, take its settings (&format=json) instead.

<initialis-cap src="https://initialis.azlen.me/?i=iPqsVuiDIn" size="200"></initialis-cap>

Growing in

grow plays it growing in once it's on screen; loop plays it again and again.

<initialis-cap seed="31" size="200" grow></initialis-cap>

Fresh ones

With seed, a fresh initial as the field makes them (the same seed gives the same one); with neither src nor seed, a new one each load.

<initialis-cap seed="1" size="120"></initialis-cap>

In a script

Into a canvas of your own: draw, grow, render (an ImageBitmap), settings (the full settings, from settings, a share link or code, or a downloaded .json) and random. Settings are plain objects, to change as you like: the same initial as another letter, in other inks.

import { draw, grow, settings, random } from 'https://initialis.azlen.me/lib/initialis.js';

const canvas = document.querySelector('canvas');
await draw(canvas, { text: 'Q', frame: 'circle' });               // its size: the canvas's own on the page
const P = await random(7);                                        // a fresh one's settings
await grow(canvas, { ...P, text: 'M', inkA: '#23305e' }, { seconds: 2.4, paper: true });
